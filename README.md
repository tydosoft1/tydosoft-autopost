# tydosoft-autopost

Автопостинг для канала [@tydosoft](https://t.me/tydosoft).

**Как работает**
1. Пн/Ср/Пт утром Claude находит свежие новости Spotify и акции в дешёвых регионах,
   пишет пост в стиле канала и кладёт его в `drafts/`.
2. GitHub Actions присылает черновик в личку от бота с кнопками **✅ Опубликовать / 🗑 Пропустить**.
3. Жмёшь ✅ — пост уходит в канал.

Поправить текст: ответь боту на черновик своей версией — придёт новая с кнопками.
Свой пост: просто пришли боту текст.

**Картинки.** Рядом с постом можно положить обложку с тем же именем
(`drafts/2026-11-02.html` + `drafts/2026-11-02.png`) — пост придёт и опубликуется с ней.
Обложки рисует `tools/cover.py` (новости — с большим эмодзи, акции и цены — с крупной цифрой).
Подпись под картинкой в Telegram — до 1024 символов.

**Файлы**
- `config/offers.md` — твои цены, акции, контакты. Держи актуальными.
- `drafts/` — все черновики (по ним Claude следит, чтобы не повторяться).
- `bot/` — код бота (Python, без зависимостей).
- `.github/workflows/` — отправка черновиков и проверка кнопок раз в ~10 минут.

**Секреты** (Settings → Secrets and variables → Actions → New repository secret)
- `BOT_TOKEN` — токен от @BotFather
- `OWNER_ID` — твой Telegram ID (узнать у @userinfobot)

Необязательно: переменная `CHANNEL` (вкладка Variables), если канал сменит юзернейм. По умолчанию `@tydosoft`.

**Проверка вручную:** Actions → «Отправить черновик в Telegram» → Run workflow — переотправит последний черновик.
